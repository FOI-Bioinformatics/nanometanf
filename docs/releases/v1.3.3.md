## 🆕 Features Implemented

### 1. Intelligent Timeout with Grace Period ✨

**Purpose**: Automatic pipeline stop after N minutes of file inactivity

**Implementation Details:**

- Two-stage timeout mechanism:
  - **Detection timeout**: Triggers after `--realtime_timeout_minutes` without new files
  - **Grace period**: Waits `--realtime_processing_grace_period` minutes for downstream processing
- Smart reset: Automatically resets timeout if new files arrive during grace period
- Clear logging: Progress updates during grace period

**Usage:**

```bash
nextflow run foi-bioinformatics/nanometanf \
  --realtime_mode \
  --realtime_timeout_minutes 10 \
  --realtime_processing_grace_period 5
```

**Technical Details:**

- File: `subworkflows/local/realtime_monitoring/main.nf` (lines 40-132)
- Implementation: Heartbeat channel using `Channel.interval('1min')` with `.until{}` operator
- Test Coverage: 6 integration tests

---

### 2. Adaptive Batching 📊

**Purpose**: Dynamic batch size adjustment with min/max constraints

**Features:**

- Automatically scales batch size between configurable min/max bounds
- Uses scaling factor for fine-tuned control
- Optimizes throughput based on sequencing speed

**Usage:**

```bash
nextflow run foi-bioinformatics/nanometanf \
  --adaptive_batching true \
  --min_batch_size 5 \
  --max_batch_size 30 \
  --batch_size_factor 1.5
```

**Technical Details:**

- File: `subworkflows/local/realtime_monitoring/main.nf` (lines 134-153)
- Logic: `batch_size = constrain(base_size * factor, min_size, max_size)`
- Test Coverage: 10 edge case tests

---

### 3. Priority Sample Routing 🚀

**Purpose**: Process high-priority samples before normal samples

**Features:**

- Channel branching with priority stream mixed first
- Flexible pattern matching (exact match, substring contains, or regex)
- Clear priority detection logging

**Usage:**

```bash
# Exact/substring matching
nextflow run foi-bioinformatics/nanometanf \
  --priority_samples "urgent,control,barcode01"

# Regex pattern
nextflow run foi-bioinformatics/nanometanf \
  --priority_samples "barcode0[1-5]"
```

**Use Cases:**

- Urgent pathogen detection
- Clinical diagnostics
- Control samples

**Technical Details:**

- File: `subworkflows/local/realtime_monitoring/main.nf` (lines 155-190)
- Implementation: `.branch{}` operator with priority-first mixing
- Test Coverage: Comprehensive pattern matching tests

---

### 4. Per-Barcode Metadata Extraction 🏷️

**Purpose**: Automatic barcode detection from filenames

**Features:**

- Regex extraction of `barcode(\d+)` from filenames
- Stored in `meta.barcode` field for downstream use
- Foundation for barcode-specific operations

**Technical Details:**

- File: `subworkflows/local/realtime_monitoring/main.nf` (lines 197-214)
- Pattern: `filename =~ /barcode(\d+)/`
- Future use: Per-barcode batching, barcode-specific reporting

## 🐛 Bug Fixes

### dorado_path Parameter Fix

**Issue**: Parameter `--dorado_path` existed but was not used in the basecaller module (hardcoded 'dorado' command)

**Fix**: Dorado command now properly respects `--dorado_path` parameter

**Impact**: Users can now specify custom dorado installations without PATH modification

**Usage:**

```bash
nextflow run foi-bioinformatics/nanometanf \
  --use_dorado \
  --dorado_path /custom/path/to/dorado
```

**Technical Details:**

- File: `modules/local/dorado_basecaller/main.nf`
- Implementation: `def dorado_cmd = params.dorado_path ?: 'dorado'`
- Test Coverage: 5 unit tests
