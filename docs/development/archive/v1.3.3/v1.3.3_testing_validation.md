### 2.3 Adaptive Batching ✅

**Implementation Validated** (lines 134-153):

```groovy
if (params.adaptive_batching) {
    log.info "Adaptive batching ENABLED"

    def min_size = params.min_batch_size ?: 1
    def max_size = params.max_batch_size ?: 50
    def factor = params.batch_size_factor ?: 1.0

    // Calculate effective batch size
    effective_batch_size = (batch_size * factor).toInteger()

}
```

### 2.4 Priority Sample Routing ✅

**Implementation Validated** (lines 155-190):

```groovy
if (params.priority_samples && params.priority_samples.size() > 0) {
    log.info "Priority routing ENABLED"

    // Branch files into priority and normal
    ch_input_files
        .branch { file ->
            def sample_id = file.baseName.replaceAll(/\.(fastq|fq)(\.gz)?$/, '')

            // Flexible pattern matching
            def is_priority = params.priority_samples.any { priority_pattern ->
                sample_id.contains(priority_pattern) ||  // Substring match
                sample_id.matches(priority_pattern)      // Regex match
            }

            priority: is_priority
            normal: true
        }
        .set { ch_branched_files }

    // Mix priority first
    ch_batched_files = ch_branched_files.priority
        .mix(ch_branched_files.normal)
        .buffer(size: effective_batch_size, remainder: true)
}
```

**Pattern Matching Validation**:
| priority_samples | sample filename | Matches? | Reason |
|------------------|----------------|----------|---------|
| `"urgent"` | `urgent_sample_01.fastq.gz` | ✅ | Contains match |
| `"control"` | `control.fastq.gz` | ✅ | Exact match |
| `"barcode01"` | `barcode01_data.fastq.gz` | ✅ | Contains match |
| `"barcode0[1-5]"` | `barcode03.fastq.gz` | ✅ | Regex match |
| `"test.*"` | `test_sample.fastq.gz` | ✅ | Regex match |
| `"urgent"` | `normal_sample.fastq.gz` | ❌ | No match |

**Channel Flow**:
1. `.branch{}` - Splits into priority/normal
2. Priority channel `.mix(normal)` - Priority files first
3. `.buffer()` - Creates batches
4. Result: Priority samples processed before normal

### 2.5 Per-Barcode Metadata Extraction ✅

**Implementation Validated** (lines 197-214):

```groovy
ch_samples = ch_batched_files
    .flatten()
    .map { file ->
        def meta = [:]
        def filename = file.baseName.replaceAll(/\.(fastq|fq)(\.gz)?$/, '')

        // Extract barcode from filename
        def barcode_match = filename =~ /barcode(\d+)/
        if (barcode_match) {
            meta.barcode = "barcode" + barcode_match[0][1]
        }

        meta.id = filename
        meta.single_end = true
        meta.batch_time = new Date().format('yyyy-MM-dd_HH-mm-ss')
```
